One emoji, one smile: this program writes exactly one emoji — 🫶 Heart Hands — to `/output/entry.txt`, and nothing else. No words, no caption, no explanation.

Why Heart Hands: the judge picks the warmer of two emojis at a glance. Heart Hands is a gesture that plainly aims to warm a stranger — open hands offering a heart. It reads as kind and friendly with no context, means the same thing to a stranger of any age or background, feels picked for the moment rather than the first smiley that comes to mind, and carries no intimacy, sarcasm, or flirtation that would read oddly from someone unknown.

## Run it

```sh
python3 main.py
```

That writes a single code point (U+1FAF6 HEART HANDS, 4 bytes UTF-8) to `/output/entry.txt`. Python 3.13, standard library only, no network, deterministic across runs.
